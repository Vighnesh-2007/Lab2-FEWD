
# Experiment 2: Branching and Merging

## Aim
To create multiple branches and merge feature branches into the main branch.

## Procedure
1. Create a feature branch.
2. Add a feature file.
3. Commit changes to the feature branch.
4. Create a pull request.
5. Merge the feature branch into main.

## Result
Successfully created a feature branch and merged it into the main branch using GitHub.
